# Humanlike Communication

A human-centered AI skill for natural, attentive, empathetic, context-aware communication.

## Install with npx skills

```bash
npx skills add https://github.com/jasspro15-jpg/humanlike-communication --skill humanlike-communication
```

List available skills:

```bash
npx skills add https://github.com/jasspro15-jpg/humanlike-communication --list
```

Global installation:

```bash
npx skills add https://github.com/jasspro15-jpg/humanlike-communication --skill humanlike-communication -g
```

This skill improves naturalness, empathy, context awareness, clarity, and truthful communication. It does not claim that an AI is human or guarantee bypassing AI detectors.
